# AI 阅读工作台 · 功能规格书

## 项目定位

**AI 阅读工作台**：一个帮助用户"读得懂、读得快"的本地阅读应用。核心解决两类问题——知识型书籍结构混乱读得稀里糊涂、小说/古文阅读时人名地名与语序造成理解障碍。

| 维度 | 决策 | 说明 |
|---|---|---|
| 产品形态 | **本地 PWA 单页应用** | iPhone 主用，不用上架 App Store，添加到主屏幕即像原生 App |
| 技术底座 | **IndexedDB 本地资产库 + DeepSeek API** | 数据存本机，AI 走真实大模型 |
| AI 架构 | **自建编排层** | 模型判断 + 规则兜底，复刻豆包知识树方法论 |
| UI 风格 | **松石·暖沙** | 清新自然浅色：纸底 #F2ECDF · 墨文 #2C3B38 · 松石绿 #3F7F76 |

## 功能清单

### A 核心 · 知识树重构（核心场景）

| 编号 | 功能 | 细节 |
|---|---|---|
| A1 | **书籍获取（自动下载）** | **全自动下载 agent，MVP 必做。** 输入书名 → agent 从 Z-Library 镜像下载 → 存本地。先搭框架，下载 agent 实现待用户抽空填入（预留输入书名返回本地路径的接口占位）。 |
| A2 | **知识树生成** | **整本书一棵大树**：核心观点 → 分论点 → 论据；剔除重复废话；按章分批生成（避免超上下文）。 |
| A3 | **树末梢原文展开** | 每个最末端节点可展开对应正文原文。**原文按树结构重构排列**（原本在 p500 的文段，树结构下可能排到靠前），非原书页码顺序。 |
| A4 | **阅读器** | **默认只读知识树**；读不懂时点击节点展开跳原文细节。**不做双栏**。 |
| A5 | **处理流水线** | 后台分步：解析 → 切章 → 知识树 → 实体识别 → 关联原文。进度可见、断点续跑，约 20 分钟/本。 |
| A6 | **处理进度 UI** | 分步进度界面（用户专门要求的设计项）。 |

### B 辅助 · 划线 / 识别（补盲区）

| 编号 | 功能 | 细节 |
|---|---|---|
| B1 | **划句白话翻译** | 选中拗口/翻译腔/文言句 → 「翻成大白话」按钮，实时调模型生成白话重述。 |
| B2 | **人名识别 + 人物卡** | **边读边识别**人名（可点击高亮）→ 点击弹人物卡。书中人物：给前文背景回顾；历史人物：**百科取硬事实 + 模型润色上下文**（准且省）。 |
| B3 | **地点识别 + 地方卡** | AI 识别地名（可点击高亮）→ 点击弹卡：书中时间线对应的位置/气候/人文。战争场景：**模型文字描述 + 手绘式 SVG 地形简图**（攻守方向、谁占哪）。 |

### C 基础能力

| 编号 | 功能 | 细节 |
|---|---|---|
| C1 | **API 接入** | 封装好调用逻辑，应用内提供配置入口（设置页手动填 Key 一键保存）。DeepSeek Key 待用户购买。 |
| C2 | **阅读进度** | 记录读到哪里、树展开到哪里。 |
| C3 | **持久化 + 资产化** | IndexedDB 本地存储；**处理结果资产化**——已处理的书/知识树/索引永久缓存，重开不重算。 |
| C4 | **缓存策略** | 三层：**永久缓存**（文本/树/索引）、**点击实时**（人物卡/地方卡/翻译）、**生成后缓存**（实时生成结果存一份，二次点击直接读，不重复花钱）。 |

## 已确认的关键决策

- **不要本地导入路径**：书籍获取走全自动下载 agent，不做手动上传。
- **不做双栏阅读器**：默认读知识树，需要细节才跳原文。
- **原文按树重构排列**，非原书页码顺序。
- **历史人物背景**：百科硬事实 + 模型润色组合。
- **战争地形**：文字描述 + 手绘 SVG 简图，不用真实地图 API。
- **API Key**：封装好 + 应用内配置。
